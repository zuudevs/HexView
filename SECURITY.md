# Security Policy

## Supported Versions

Currently, only the latest active development branch and version `1.0.x` are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 0.5.x | :x:                |

## Reporting a Vulnerability

Security is a priority for HexView. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by sending an email directly to the maintainers or by opening a private GitHub Security Advisory in this repository.

We will acknowledge your report within 48 hours, and we'll provide an estimated timeline for resolution. Once the issue is resolved and a patch is released, we will acknowledge your contribution (if you wish) in our release notes.
